# 🎮 Liminal Horror Game

Атмосферная 2D игра на Rust с процедурной генерацией бесконечного лиминального уровня.

## ✨ Особенности

- **Процедурная генерация текстур** - Каждый запуск создает уникальные текстуры с помощью Perlin Noise
- **Бесконечный уровень** - Лиминальный мир генерируется по мере движения
- **Жуткая атмосфера** - Холодные тона, сетчатый паттерн, пульсирующий туман
- **Опасные зоны** - Красные области добавляют атмосферу опасности
- **Оптимизация** - Динамическая загрузка и выгрузка чанков

## 🚀 Установка и запуск

### Требования
- Rust 1.70+
- Cargo

### Запуск

```bash
cargo run
```

Для оптимизированной сборки:
```bash
cargo run --release
```

## 🎮 Управление

- **W** / **↑** - Вверх
- **S** / **↓** - Вниз
- **A** / **←** - Влево
- **D** / **→** - Вправо

## 📦 Зависимости

- **bevy** - Игровой движок
- **noise** - Perlin noise генератор
- **rand** - Случайные числа

## 🏗️ Структура проекта

```
src/
├── main.rs              # Главной цикл игры, управление камерой, чанки
├── texture_generator.rs # Процедурная генерация текстур
├── level_generator.rs   # Генератор уровней из чанков
└── atmosphere.rs        # Атмосферные эффекты (туман)
```

## 🎨 Генерация текстур

### Лиминальные текстуры
Создаются комбинацией нескольких слоев Perlin noise с холодными оттенками и сетчатым паттерном.

### Жуткие детали
Темные пятна и загрязнения добавляют ощущение запущенности.

### Опасные зоны
Красные области указывают на потенциальные опасности.

## 🔧 Параметры, которые можно настроить

В `src/texture_generator.rs`:
- `noise1 * 0.5 + noise2 * 0.3 + noise3 * 0.2` - Коэффициенты смешивания шумов
- `64.0, 32.0, 100.0` - Масштабы шумов
- Значения цветов (RGB) для лиминального эффекта
